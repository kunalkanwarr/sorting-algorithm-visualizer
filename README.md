# 🔢 Sorting Algorithm Visualizer

🚀 **An interactive web application that visualizes sorting algorithms step by step using smooth animations.**  
This project helps beginners understand sorting algorithms visually instead of only reading theory.

---

## 🧠 Algorithms Implemented
- ✅ Bubble Sort
- ✅ Selection Sort
- ✅ Insertion Sort
- ✅ Quick Sort
- ✅ Merge Sort

---

## 🎛 Features
- ✨ Dynamic number of bars using a slider  
- ⚡ Adjustable sorting speed  
- 🎨 Color-coded comparisons, swaps, and sorted elements  
- 🎥 Smooth animations using **async / await**  
- 📱 Responsive UI built with Bootstrap  

---

## 🛠 Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Bootstrap 5**
